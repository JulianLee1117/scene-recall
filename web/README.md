# Scene Recall web app

This is the Next.js interface for Scene Recall. Use the repository-level
[`README.md`](../README.md) for setup, backend, ingestion, and architecture
links.

```bash
npm install
npm run dev
```

The frontend expects the FastAPI service at the URL configured in
`web/.env.local`. Before changing framework code, follow [`AGENTS.md`](AGENTS.md)
and read the matching local Next.js documentation under `node_modules`.
