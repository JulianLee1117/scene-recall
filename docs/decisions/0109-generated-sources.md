# ADR-0109: Generated sources: AI clips placed in edits like film shots

- Status: Accepted
- Date: 2026-10-05
- Extends: ADR-0108 (screens and push-ins)
- Supersedes: None (decides the editor-integration gate ADR-0071 left open,
  for explicit placement only)
- Superseded by: None

## Context

ADR-0108 pushes into a TV screen by zooming the picture through keyed corners.
The owner judged the result amateur: the scene on the screen did not stay
matched to a moving screen, and the push stretched one picture to fill the
frame. They asked to use Runway for pushes and for bolder AI transitions, and
earlier asked that agent-built edits stay openable in the Lab editor.

The frozen Transitions Lab (ADR-0070 to ADR-0076) can generate and import AI
bridges, but only as projectless auditions. ADR-0071 gated editor integration
on played quality, continuity, latency and cost. Probes on one push (an
upright TV in *Mirror* into its own broadcast, first and last frames given):

| Model | Credits/s | Latency (4 s) | Result |
|---|---|---|---|
| Veo 3.1 Fast | 10 | 56 s | A morph: the boy turns into a viewer of another TV, no push |
| Veo 3.1 | 20 | 61 s | The same morph |
| Seedance 2 Fast | 29 | 165 s | A real dolly push into the screen that comes out into the last frame |

Both endpoints hold, so the cut into and out of the clip is continuous. One
4-second Seedance push costs 116 credits ($1.16).

## Decision

1. **A generated clip is a source.** It is registered by content: its bytes are
   copied to `state_dir/lab/generated/gen-<sha256[:20]>.mp4`, and one row in a
   `lab_generated` table holds its film-shaped identity (`film_id`, title,
   path, duration, fps) and provenance (provider, model, prompt, endpoint
   frames). Registering the same bytes again returns the same row.
2. **Placement is explicit.** A document places a generated clip as an
   ordinary clip or effect source with its `gen-` ID. Source resolution falls
   back to `lab_generated` only for `gen-` IDs, so validation, renders, OTIO
   export, effects and the browser player work unchanged. The API streams the
   original bytes (no playback proxy).
3. **The library never sees them.** Search, ingestion and the `films` table do
   not include generated rows; nothing indexes or annotates them.
4. **Generation stays outside the editor.** Clips are generated by whoever
   builds the edit (an agent script or the frozen Transitions Lab) and then
   registered with `python -m pipeline.lab.generated register`. The editor
   does not choose, request or pay for AI transitions.

## Consequences

- AI pushes and transitions in an agent edit open, play and render in the Lab
  like any other edit, and export to Resolve as clips on their own media.
- The `lab_generated` table lives in the index database, so editor snapshots
  pin it with the library. Its writes take the same locks as publication.
- Generated media is kept; nothing deletes it yet.
- Automatic selection and in-editor generation remain gated as in ADR-0071.
