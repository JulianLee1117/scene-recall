# Review pages

Some experiments were reviewed on web pages rather than in this repository:
rendered edits with the owner's timestamped notes, effect boards, and audits
with full-size sheets. This is the index of those pages. Each row links the
page and records what it showed and what came of it, so the history keeps
even if a page goes. A page opens only for its owner unless it has been
shared from its Share menu; the ones marked open by link can be opened by
anyone who has the link.

New review pages get a row here.
